## 2025-02-18 - Manual WebGL/GPU Memory Cleanup in React Three Fiber (R3F)
**Learning:** In React Three Fiber (R3F), while standard JSX-declared geometries and materials (e.g. `<boxGeometry />`) are automatically disposed of when unmounted, any Three.js objects instantiated imperatively inside Javascript/Typescript (e.g., inside `useMemo` blocks) are not garbage-collected or cleaned up by R3F. If left untreated, they leak GPU memory (buffers, shader programs) every time their memoization dependencies change or when the R3F Canvas component is unmounted during route navigation (e.g., navigating away from the homepage).
**Action:** Always implement a manual `useEffect` cleanup function calling `.dispose()` on imperatively allocated Three.js objects (such as `BufferGeometry` and `ShaderMaterial`) to prevent WebGL GPU memory leaks and keep the application performant during navigation and hot reloading.

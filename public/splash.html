Why a vanilla page exists in a React app

  • Browsers execute exactly three languages: HTML for structure, CSS for style, JavaScript for behavior. TypeScript is JavaScript with types — it compiles down to the same JS.
  • This page proves the point: every effect you see here (the sonar sweep, the live clock, these cards) is plain DOM APIs and canvas. No framework required — frameworks just scale that up for big apps.
  • Elsewhere in this repo, Python and C do build-time work — checking screenshots, validating assets, generating the metrics dataset. The browser never runs them; the data they produce is what the app renders. Every language in its natural habitat.
